# Model Context Protocol (MCP) - .Net 10

## Projenin Temel Maksadı

Model Context Protocol (MCP) projesi, yapay zekâ uygulamalarının dış sistemlerle iletişim kurmasını ve belirlenen araçları (Tools) kullanarak gerçek işlemler gerçekleştirmesini sağlayan bir protokolün .NET ile uygulanmasını amaçlamaktadır.

ASP.NET Core 10.0 Web API temelli proje içerisinde Model Context Protocol (MCP) kullanılarak AI modellerinin Tool'lar aracılığıyla sistemlerle etkileşim kurması sağlandı. MCP Server oluşturma, AI araçlarının entegrasyonu, Tool tanımlama ve JWT tabanlı kimlik doğrulama süreçleri ele alındı.
